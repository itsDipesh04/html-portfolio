# Navigation Menu Hover Animation

A clean, minimalistic navigation menu component featuring a smooth CSS pseudo-element hover effect. This project is ideal for landing pages or as a boilerplate for a modern website header.

## Features
- **Modern UI:** Uses a centered card layout with a subtle drop shadow.
- **Smooth Animation:** Features an animated underline effect that expands from left to right on hover.
- **Responsive Foundation:** Uses a flexible container that fills the viewport (`100vh`).
- **Clean Typography:** Pre-configured to use the 'Poppins' font family.

## File Structure
- `index.html`: Contains the structural markup for the navigation bar.
- `style.css`: Contains the styling and the transition logic for the hover animations.

### CSS Animation Logic
The hover effect is achieved using the `::after` pseudo-element on the list items:
- **Initial State:** The `::after` element is positioned at the bottom with a `width` of `0`.
- **Hover State:** When the user hovers over a menu item, the `width` transitions to `100%`.
- **Transitions:** A `0.5s` transition ensures the movement is fluid and professional.
